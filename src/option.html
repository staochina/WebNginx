WebNginx

Server Rules

规则按 server 分组；server_name 必填；每行一个 location。须 Save and Sync 后生效。完整说明见 README。

工作原理
  • MITM 透明代理：纯 proxy_pass（无 rewrite/return）→ PAC + 本地 Native Host；地址栏域名不变。
  • DNR：rewrite / return / 纯改 Header，或同 Location 把 proxy_pass 与 rewrite/return 写在一起 → 退回浏览器侧规则。
  • 每个 server 必须有非空 server_name；弹窗总开关关闭会清空 DNR 与 PAC。
操作与填写说明
  • 编辑 / Import 只改本页；必须 Save and Sync。未保存关闭会丢失。
  • server_name 必填（可空格写多个域名）。Location：前缀 /、/api，或正则 ~ / ~*。
  • 指令：proxy_pass、rewrite、 proxy_set_header、add_header、 return 403|444（每行以 ; 结尾）。
  • 同 server 内更靠下的 Location 优先（可拖动 ⋮⋮）。Inactive 不参与。
  • Export / Import 使用 nginx 风格 .conf；Import 整体替换编辑区。
  • Debug 立即开关，只打控制台 [WebNginx] 日志，不落盘。
  • 示例：server_name www.abcd.com + proxy_pass http://127.0.0.1:8080; → MITM（需 Host / CA，见下一栏）。
本地 Host 与 CA（从零安装）

仅 MITM（透明 proxy_pass）需要 Host / CA；纯 DNR 只需加载扩展（可以从谷歌应用商店安装 WebNginx，或本地加载）。下面按顺序做，命令在webnginx-native安装目录执行。

  1. 可以从谷歌应用商店安装 WebNginx；或 Chrome 打开 chrome://extensions → 开发者模式 →「加载已解压的扩展程序」→ 选 src/（或 make buildc 后解压 zip）。
  2. 复制该扩展的 ID。
  3. 终端：make install-host EXT_ID=你的ID（只装 Native Messaging， 不生成 CA、不写钥匙串）。
  4. 回到 chrome://extensions，点 WebNginx 重新加载。
  5. 打开本页（Options）：添加 server，填 server_name，Active 勾选，写纯 proxy_pass …;（同条不要再写 rewrite/return）。
  6. 弹窗打开总开关 Enable Active Rules，再点 Save and Sync → host 启动并首次生成 ~/.webnginx/ca.crt / ca.key。
  7. 终端：make trust-ca（把 CA 写入登录钥匙串；需本机密码）。
  8. Cmd+Q 完全退出 Chrome 再打开（只关窗口不够）。
  9. 本页下方徽章应为 ON；再访问配置的域名验证。
  • 扩展 ID 变更后须重跑 install-host 并重新加载扩展；删过 ~/.webnginx/ 或换机后须再 Save 生成 CA，再 trust-ca + Cmd+Q。改端口不必重生证书。
  • 叶证书只在 host 内存；完整说明与排错见 README。
卸载与移除信任证书（macOS）

按顺序可卸干净扩展、Native Host、本地 CA 与钥匙串信任。

  1. 弹窗关掉 Enable Active Rules（清空 PAC、断开 host）。
  2. chrome://extensions → 移除 WebNginx。
  3. 删除 Native Messaging 注册文件 com.webnginx.proxy.json（目录： ~/Library/Application Support/Google/Chrome/NativeMessagingHosts/）。
  4. 删除运行时 CA：终端执行 rm -rf ~/.webnginx（含 ca.crt / ca.key）。
  5. 从登录钥匙串移除 WebNginx Local CA（只删 ~/.webnginx 不会撤销信任）：
    • 图形界面：打开「钥匙串访问」→ 登录 → 证书 → 找到 WebNginx Local CA → 删除 → 输入本机密码。
    • 命令行（证书文件还在时）： security remove-trusted-cert -d ~/.webnginx/ca.crt
    • 或按名称删除： security delete-certificate -c "WebNginx Local CA" ~/Library/Keychains/login.keychain-db
  6. （可选）删除本仓库 / webnginx-native/ 源码目录。
  7. Cmd+Q 完全退出 Chrome 再打开。
