WebNginx

Server Rules

规则按 server 分组；server_name 必填。须 Save and Sync 后生效。点击下方标签查看摘要；完整说明见 README。

  • MITM：纯 proxy_pass（同 Location 无 rewrite / return）→ PAC + Native Host，地址栏域名不变。
  • DNR：rewrite / return / 纯改 Header，或同 Location 把 proxy_pass 与 rewrite/return 写在一起 → 浏览器侧改写 / 拦截 / 改头。
  • server_name 必填；弹窗总开关关闭会清空 DNR 与 PAC。
  • 编辑 / Import 只改本页；须 Save and Sync 才生效，未保存关闭会丢失。
  • server_name 必填（多个域名用空格分隔）。Location：前缀 /、/api，或正则 ~ / ~*。
  • 指令（每行以 ; 结尾）：proxy_pass、 rewrite、proxy_set_header、add_header、 return 403|444。
  • 同 server 内更靠下的 Location 优先（可拖 ⋮⋮）；Inactive 不参与匹配。
  • Export / Import 为 nginx 风格 .conf；Import 整体替换编辑区（不合并）。
  • Debug：立即开关，仅控制台 [WebNginx] 日志，不落盘。
  • MITM 示例：server_name www.abcd.com + proxy_pass http://127.0.0.1:8080;（需 Host / CA，见相邻标签）。

仅透明 proxy_pass（MITM）需要；纯 DNR 可跳过。命令在 webnginx-native/ 执行。下方按当前系统显示步骤；完整说明见 README。

  1. 加载扩展：应用商店安装，或 chrome://extensions → 开发者模式 → 加载已解压程序 → 选 src/。
  2. 复制扩展 ID。
  3. 安装 Native Host（只注册通信，不生成 CA）：
    make install-host EXT_ID=你的ID
    使用 Git Bash（勿用纯 WSL）： make install-host EXT_ID=你的ID （可选 SHELL_KIND=sh）
  4. chrome://extensions → 重新加载 WebNginx。
  5. 本页添加规则：填 server_name，Active 勾选，写纯 proxy_pass …;（同条不要写 rewrite/return）。
  6. 弹窗打开 Enable Active Rules → Save and Sync。 首次会生成 ~/.webnginx/ca.crt（有效期 10 年；Windows： %USERPROFILE%\.webnginx\）。
  7. 信任 CA（HTTPS 必做）：
    make trust-ca → 写入登录钥匙串（需本机密码）
    make trust-ca → 写入当前用户受信任根证书
  8. 完全退出再开 Chrome： Cmd+Q（只关窗口不够；Chrome 会缓存系统证书信任） 退出任务栏/托盘图标后再打开（Chrome 会缓存系统证书信任）
  9. 本页 Proxy status 徽章为 ON，再访问配置域名验证。
  • 扩展 ID 变了 → 重跑 install-host 并重新加载扩展。
  • 删过 CA / 换机 → 再 Save 生成证书，然后 trust-ca 并完全退出 Chrome（Chrome 会缓存系统证书信任）。
  • 只改 Listen port → Save and Sync 即可，不必重生或重信任 CA。

按顺序卸干净扩展、Host、本地 CA 与系统信任。下方按当前系统显示；详见 README。

  1. 弹窗关掉 Enable Active Rules。
  2. chrome://extensions → 移除 WebNginx。
  3. 删除 Native Messaging 注册：
    删除 ~/Library/Application Support/Google/Chrome/NativeMessagingHosts/com.webnginx.proxy.json
    reg delete "HKCU\Software\Google\Chrome\NativeMessagingHosts\com.webnginx.proxy" /f
  4. 删除运行时 CA：rm -rf ~/.webnginx。
  5. 从系统信任中移除 WebNginx Local CA（只删文件不会撤销信任）：
    「钥匙串访问」→ 登录 → 证书 → 删除；或 security remove-trusted-cert -d ~/.webnginx/ca.crt
    certmgr.msc → 受信任的根证书颁发机构 → 删除；或 certutil -user -delstore Root "WebNginx Local CA"
  6. （可选）删除 webnginx-native/ 源码目录。
  7. 完全退出再开 Chrome： Cmd+Q 含托盘退出
